# GRIMGE Transformation Concept

Ja. Dann haben wir eigentlich **drei unterschiedliche Transformationsquellen**, die jeweils eine andere Aussage über den Build des Spielers machen. Und die **Mastery Transformation** passt sehr gut als dritte Säule dazu.

Ich würde es so festhalten:

| Transformation | Quelle | Aussage |
|---|---|---|
| ⚔️ **Class Transformation** | Class Tree | Meisterschaft der eigenen Klasse |
| 🐉 **Primal Transformation** | Primal Bond | Verschmelzung mit dem ausgerüsteten Primal |
| ✦ **Mastery Transformation** | Rune Mastery | Meisterschaft einer magischen Schule |

## Class Transformation

Jede Klasse besitzt ihre eigene Transformation, die über den **Class Tree** erreicht wird.

Sie verändert den Charakter passend zur Klassenidentität, also beispielsweise Silhouette, Kleidung/Rüstung, Waffenwirkung, Aura und gegebenenfalls Animation/VFX.

Das ist die Transformation:

> **„Ich habe meine Klasse gemeistert.“**

Sie ist deshalb unabhängig von Runen und Primals.

## Primal Transformation

Hier würde ich exakt bei unserem bereits besprochenen Drei-Stufen-System bleiben.

### Primal Stage I: Manifestation

Der Charakter selbst bleibt als Sprite grundsätzlich erhalten. Um ihn herum manifestiert sich die Energie beziehungsweise Silhouette des Primals.

Ähnlich vom Prinzip Naruto/Kyūbi:

> Aura, Energie, Augen/VFX, Umriss des Wesens

aber noch **keine vollständige körperliche Veränderung**.

### Primal Stage II: Hybrid

Der Primal wird körperlicher Bestandteil des Charakters.

Je nach Primal beispielsweise:

- Hörner
- Klauen
- Schweif
- Flügel
- Fell
- Schuppen
- veränderte Augen
- andere Körpermerkmale

Charakter und Primal sind aber weiterhin klar als zwei Ursprünge erkennbar.

### Primal Stage III: Fusion

Vollständige Fusion.

> **Character × Primal**

Das darf visuell richtig eskalieren und eine der prestigeträchtigsten Formen des Spiels sein.

Die drei Stufen werden über das **Primal Level/Bond Progression** freigeschaltet.

# Mastery Transformation

Das würde ich tatsächlich **für jede der 14 Masteries** machen.

Das bedeutet:

- 🔥 Fire Mastery Transformation
- 💧 Water Mastery Transformation
- ❄️ Ice Mastery Transformation
- 🌪 Wind Mastery Transformation
- ⚡ Lightning Mastery Transformation
- 🪨 Earth Mastery Transformation
- 🌿 Nature Mastery Transformation
- ☀️ Light Mastery Transformation
- 🌑 Shadow Mastery Transformation
- 🕳 Void Mastery Transformation
- 👁 Invocation Mastery Transformation
- 🏗 Construction Mastery Transformation
- 🛡 Ward Mastery Transformation
- 🎯 Control Mastery Transformation

Das ist dann:

> **„Ich habe diese Form der Magie so weit gemeistert, dass mein Charakter selbst zu ihrem Ausdruck wird.“**

Und hier würde ich **nicht drei Stufen** machen. Das ist die Besonderheit der Primals.

Mastery Transformation wäre **eine Endgame-Belohnung am Ende eines Mastery Trees**.

---

# Die Mastery Transformations sollten extrem unterschiedlich sein

Auch hier bitte nicht:

> Fire = rote Aura  
> Ice = blaue Aura  
> Lightning = gelbe Aura.

Sondern die Mastery verändert die visuelle und mechanische Identität.

## 🔥 Fire Mastery

Körper teilweise glühend, Haare/Outfit reagieren wie Flammen, Aschepartikel, Hitzeverzerrung.

## ❄️ Ice Mastery

Kristalline Körper-/Rüstungselemente, Frostatem, Eisbildung an Bewegungen.

## ⚡ Lightning Mastery

Elektrische Entladungen zwischen Körperteilen, extrem energetische Bewegungseffekte.

## 🌿 Nature Mastery

Organische Veränderungen, Ranken/Blätter, vielleicht spirituelle Naturmerkmale.

## 🌑 Shadow Mastery

Körper teilweise in Schatten aufgelöst, verzerrte Silhouette.

## 🕳 Void Mastery

Teile des Körpers wirken dimensional gebrochen, kleine Rifts, Raumverzerrung.

Und auch die Concepts dürfen richtig interessant werden.

## 👁 Invocation Mastery Transformation

Könnte den Charakter von mehreren geisterhaften Manifestationen umgeben lassen.

## 🏗 Construction Mastery Transformation

Könnte schwebende Arcane Constructs/Runenfragmente um ihn herum erzeugen.

## 🛡 Ward Mastery Transformation

Könnte aus mehreren sich bewegenden magischen Schutzringen/Platten bestehen.

## 🎯 Control Mastery Transformation

Könnte Raum, Partikel und Objekte sichtbar um den Charakter herum verzerren.

Damit sind auch die vier Discipline Masteries visuell genauso wertvoll wie Elemente.

# Gameplay

Transformationen dürfen natürlich stark und mächtig wirken. Aber vermieden werden sollte:

> Mastery 100 = Transformation = automatisch +50 % Damage.

Jede Transformation sollte eher eine **eigene temporäre Regeländerung** geben.

Beispielsweise könnte die Fire Mastery Transformation dafür sorgen, dass Fire-Spells während der Form miteinander anders interagieren.

Control könnte Manipulationsmöglichkeiten verändern.

Invocation könnte die Beziehung zu aktiven Summons verändern.

Die konkreten Effekte sollten **erst mit den Mastery Trees designt werden**.

Denn dann kann die Transformation jeweils der finale Ausdruck genau dieses Trees sein.

# Dreifach-Progression

```text
                  CHARACTER
                      │
       ┌──────────────┼──────────────┐
       │              │              │
     CLASS          PRIMAL         MAGIC
       │              │              │
   Class Tree      Primal Bond    Mastery Tree
       │              │              │
       ▼              ▼              ▼
    CLASS         PRIMAL         MASTERY
TRANSFORMATION  TRANSFORMATION  TRANSFORMATION
                   │
             Stage I → II → III
```

Das Schöne ist:

**Jede Transformation erzählt etwas über den Spieler.**

Class Transformation zeigt, **wie er kämpft**.

Primal Transformation zeigt, **mit welchem Wesen er gebunden ist**.

Mastery Transformation zeigt, **welche Magie er gemeistert hat**.

---

# Kanonische Regel

**Jeder der 14 Mastery Trees besitzt am Ende eine einzigartige Mastery Transformation.**

Die konkreten Formen und Gameplay-Effekte bleiben vorerst offen.
